04

How a project is structured

Each project has a shared context, an overall plan, and a record of the work. The plan breaks the goal into tasks with outputs, dependencies, and deadlines. Gates mark decisions the user must make before dependent work continues.

Context

The project brief, instructions, sources, and data.

Project plan

The goal and completion criteria, task sequence, gates, and deadlines.

Project record

Current progress, decisions, outputs, and their verification status.
