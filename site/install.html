Install guide

Build your AI OS, level by level

Start with one instructions file and add structure only when you need it. Your agent installs each level from the public library and waits for your decision before the next.

Install kit v0.1.0 · library v2.0.1 — September 27, 2026

Download the kit and library (.zip) Or clone the repository ↗
01

One instruction to begin

Unzip the download, or clone the repository. Open your agent (Claude Code, Codex, or another tool that can read files) in that folder and say:

Read install-kit/START-HERE.md and help me choose my levels.

The agent explains the levels, you choose, and it installs them one at a time. Each level ends at a gate: the agent shows you what it did and waits for your decision. You can stop after any level.

02

Five levels

  1. L0

    Instructions file

    One short file your agent reads at the start of every session: who you are, the two guiding principles, your working rules, and your red lines.

    Needs
    Nothing.
    You decide
    Where the file lives, and every rule in it.
    Done when
    A fresh session's first reply reflects your principles.
    Follows
    Setup protocol, Phase 4
  2. L1

    Library

    Your own copy of the personas and protocol skills, with your paths and names filled in and connected to your agent tool.

    Needs
    Nothing (L0 optional).
    You decide
    Every value filled in, and how the library is connected to your tool.
    Done when
    A persona activates and a skill resolves in each tool you use.
    Follows
    Setup protocol, library setup, library connection
  3. L2

    Project

    A project folder another session can pick up: an entry point, a roadmap, separate places for sources, working files and outputs, an asset registry, and an interaction log.

    Needs
    L1 recommended.
    You decide
    The project, its rules, and, for an existing folder, how much to reorganize.
    Done when
    You approve the folder tree and the list of changes.
    Follows
    New project, existing folder
  4. L3

    Bookkeeping

    Hooks in Claude Code or Codex record sessions, file claims, checkpoints and closeouts for the projects you select. This level also creates the projects ledger.

    Needs
    A project folder you own, Python 3.11+ and Git. All sessions closed.
    You decide
    Which projects, and whether to trust each new hook.
    Done when
    A fresh session registers, checkpoints and closes with a verified record.
    Follows
    Installation guide, project registration
  5. L4

    Portfolio

    Routines for working across projects: a chief of staff that reads the ledger at the start of a session, a periodic library review, and recovery of a lost session.

    Needs
    L3 (for the ledger) and L1 (for personas and the librarian).
    You decide
    Which routines to take, and how each one is checked.
    Done when
    The checks you approved pass.
    Follows
    Chief of staff, librarian, session recovery
03

Pick your levels

Choose any level whose prerequisites you already have or are also choosing. Some common combinations:

L0

Just the rules

Every session starts from your principles and red lines. Nothing else to maintain.

L0 + L1

A working library

Personas and skills for recurring tasks, adapted to your work.

L0 + L1 + L2

One well-kept project

A project another session can resume, with records kept by the agent.

L0 – L4

The full system

Automatic records across several projects, and routines that keep them in view.

04

When the agent stops and asks

Before it

  • installs software or changes a program's version;
  • edits global agent settings or hooks;
  • writes outside the library and the project folders you named;
  • changes permissions or trust settings;
  • pushes, publishes or uploads anything;
  • registers a project or changes a ledger;
  • deletes, overwrites or moves a file you made.

And always

  • Unknown values are written OPEN, never guessed.
  • Folders are snapshotted before they are edited in place.
  • The installer runs as a dry run first.
  • Your level choice and every gate decision are recorded verbatim in install-state.md.
