# Fixture defects

Every folder is a copy of `ok/` with exactly one defect. Every copy inherits `ok/`'s `W-UNTYPED` (D-009, produced by T-007, is untyped on purpose). Label hashes are recomputed after each defect except in `warn-W-STALE-LABELS`. Run `python run_tests.py`. The folders are generated by `_gen/build_fixtures.py` (see `_gen/README.md`); edit the generator, not the folders.

A folder name may carry a lowercase suffix after the rule (`fail-E-STRUCTURE-dp`) when one rule has more than one defect type; `run_tests.py` strips the suffix to get the expected rule.
